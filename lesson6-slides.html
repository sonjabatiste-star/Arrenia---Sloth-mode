Concept

Classifying the Number System

Numbers nest inside each other like a set of Russian dolls:

Rational
Integers
Whole

Whole numbers (0,1,2,3...) are integers. Integers (...,-2,-1,0,1,2...) are rational numbers.

Concept

The Coordinate Plane, All Four Quadrants

The x-axis and y-axis divide the plane into four quadrants. The sign of each coordinate tells you which quadrant a point is in:

QI: (+,+)QII: (−,+) QIII: (−,−)QIV: (+,−)

Plotting & Reflecting Points

Plot the point (4, −2), then reflect it across the y-axis.

Original point: (4, −2) is in Quadrant IV.
Reflecting across the y-axis flips the sign of x only: (−4, −2), now in Quadrant III.

Challenge

Mixed Review Problem

Order from least to greatest, then identify which are integers: −2.5, 1/2, −3, 0.75

As decimals: −2.5, 0.5, −3, 0.75
Ordered: −3, −2.5, 1/2, 0.75
Only −3 is an integer — the rest are non-integer rational numbers.
